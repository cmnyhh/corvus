# Dronepal · 实施计划（1.21.1 / NeoForge）

> ⚠️ **交接请读 [SPEC.md](SPEC.md)**：自包含执行规格（含已核实的 TaCZ API 事实、全部数值、已知坑、否决清单）。

> 目标验收（一句话）：**在 1.21.1 整合包里召唤一架无人机，它跟着你、装了模块才有的功能能用、芯片决定它怎么说、全程不联网、不能改世界。**

## 1. 版本矩阵（锁定，先不改）

| 组件 | 版本 | 必需 | 说明 |
|---|---|---|---|
| Minecraft | **1.21.1** | ✅ | |
| NeoForge | **21.1.x**（≥21.1.190） | ✅ | 1.21.1 上 TaCZ 只有 NeoForge 版 |
| Java | **21** | ✅ | 1.21 起强制 Java 21；**本机只有 17/25，需装** |
| TaCZ | **1.2.0**（neoforge-mc1.21.1） | 可选 | `mod_link` 模块靠它 |
| Curios | 9.x（neoforge-1.21.1） | 可选 | 饰品栏；没有则退化为“召唤器物品” |
| GeckoLib | 4.7.x（neoforge-1.21.1） | 可选 | 没有则用方块模型占位 |

> 三个可选依赖全部 `compileOnly` + 运行时 `ModList.isLoaded()` 分支，**缺任何一个 mod 都能启动**。

## 2. 阶段划分（P0–P5）

每个阶段都必须“能进游戏看到东西”才算完成；不允许连续两个阶段都只写代码不验证。

### P0 · 环境与骨架（阻塞项，0.5 天）

| # | 任务 | 产出 | 验收 |
|---|---|---|---|
| P0.1 | ~~装 JDK 21~~ **本机已有**：Corretto 21.0.12.1 / MS OpenJDK 21.0.12.1，只需在 `gradle.properties` 指定 toolchain | `./gradlew -version` 显示 JVM 21 | ✅ 已满足 |
| P0.2 | 用 NeoForge MDK 生成 `build.gradle` / `gradle.properties` / `settings.gradle` | 可 `./gradlew build` | 产出空 jar |
| P0.3 | `Dronepal.java` 主类 + `neoforge.mods.toml`（`modLoader="javafml"`, `loaderVersion="[4,)"`） | mod 列表里出现 Dronepal | 进游戏能在 Mods 页看到 |
| P0.4 | 注册一个空的 `DeferredRegister`（items/blocks/entities/creative tab） | 编译通过 | 无崩溃 |
| P0.5 | 建 `run/` 客户端配置，装 TaCZ/Curios/GeckoLib 到 `run/mods` | 能进世界 | 加载无报错 |

**风险**：Gradle 首次拉 NeoForge 依赖 ~800MB，国内网络可能超时 → 备选：手动下 maven 包或换镜像。

### P1 · 实体与飞行（v0.1 核心，2~3 天）

| # | 任务 | 关键点 | 验收 |
|---|---|---|---|
| P1.1 | `DroneEntity extends PathfinderMob` | `noPhysics=true`、`setNoGravity` | 能 `/summon` 出来，不落地 |
| P1.2 | `DroneMoveControl extends MoveControl` | 目标点插值 + 悬停正弦浮动 | 移动平滑，不抽搐 |
| P1.3 | `FollowOwnerGoal`（自写） | 玩家身后 2 格偏移、>8 格加速、>16 格瞬移、>32 格回收 | 走隧道不卡墙、跑图不掉队 |
| P1.4 | 避障：每 5 tick 向前 raycast 3 格 | 撞墙沿法线侧移 | 不会穿墙“贴脸” |
| P1.5 | `DroneItem`：装备即召唤、卸下即消失（**无独立召回动作**） | 绑定物品 UUID，同 UUID 单实例 | 装回卸下反复 10 次，实体恒为 1 架 |
| P1.6 | 持久化 | 玩家下线/重生/换维度/区块卸载 | 重进游戏无人机还在身边 |
| P1.7 | 客户端渲染（先方块占位） | `EntityRenderer` + 简单材质 | 看得见 |

**风险**：跟随的手感（滞后/抖动）需要 3~5 轮调参 —— 这是本项目**唯一必须反复试玩**的部分。


### P1.5 · 真枪挂载 Spike（**前置验证，2 天，不通过就改架构**）

目的：在写模块系统之前，先证明「非玩家实体能拿 TaCZ 的真枪开火」。

| # | 任务 | 验收 |
|---|---|---|
| S1 | 无人机主手槽持有 `GunItem` + 暴露 `Capabilities.ItemHandler.ENTITY`（枪槽 + 弹匣槽） | TaCZ 能识别到枪 |
| S2 | 调 `IGunOperator.fromLivingEntity(drone)` → `draw()` → `shoot()` | **能打出一发子弹并命中** |
| S3 | 弹匣被真实消耗（`findAndExtractInventoryAmmo` 从机内库存扣） | 打完 30 发停火 |
| S4 | 枪渲染（复用 TaCZ renderer，套 `gun_mount` 变换，不缩放不额外旋转） | 第三人称看得见枪、枪口朝前、不歪 |
| S5 | 精度/AI 节流：射击间隔随机化 + 瞄准散布 + 禁止移动射击 | 不会变成自动瞄准挂 |
| S6 | **挂载实测**：手枪/步枪/狙击/RPG 各挂一次，确认「固定偏移 + 超长枪一档」够用 | 轻微穿模可接受；接缝被挂架盖住 |
| S7 | 云台 pitch：0° 交战 / +85° 收纳，过渡不穿机体、不插地 | 收纳-展开 20 次无卡死 |

**若 S2 不通过**（TaCZ 内部有玩家假设）→ 立刻回退到“自定义投射物”方案，别硬刚。

### P2 · 槽位与模块（v0.2，2~3 天）

| # | 任务 | 关键点 | 验收 |
|---|---|---|---|
| P2.1 | **状态全部放进物品 `DataComponents`**（芯片/3 模块/电池/电量） | 实体只做投影，不持有权威状态 | 拆装/死亡/换维度后数值不丢不错 |
| P2.2 | 槽位 GUI（`AbstractContainerMenu` + `Screen`），入口 = **潜行+空手右键实体** | 普通右键不做任何事（防误触）；只允许对应 `slot_type` 放入 | 战斗中右键不会弹面板；装错槽位放不进去 |
| P2.2b | **实体生命周期**：装备即 spawn、卸下即 discard、死亡/换维度/区块卸载重建 | 按 UUID 去重，冷却重建 | 任意顺序拆装/传送/死亡，实体数量恒为 1 |
| P2.2c | **充电座方块**（FE 输入 + 烧煤兜底） | `IEnergyStorage.BLOCK`，只收不放 | 电池与停靠中的无人机都能充 |
| P2.3 | 数据驱动加载（`SimpleJsonResourceReloadListener`） | chips/modules/intents/lines 四类 JSON | `/reload` 后新增模块立刻生效 |
| P2.4 | 电力系统 | `drain_watts` 累加、电量 tick 扣减、<20% 关最贵模块 | HUD 显示电量、掉电行为正确 |
| P2.5 | 模块→Goal 动态注册 | 装卸模块时增删 Goal | 拆掉 combat 后不再开火 |
| P2.6 | `mod_combat`：索敌 + **用 TaCZ 真枪开火**（复用 P1.5 结论） | 16 格、3 连发、真实消耗弹匣 | 能打死僵尸，不误伤主人，弹药真实消耗 |
| P2.7 | `mod_light`：动态光源 | 1.21 光照 API | 夜里能照亮周围 |
| P2.8 | `mod_carry`：拾取 + 投递 | 9 格机身库存（存物品组件）；投递直接塞玩家背包 | 捡东西不丢、不刷物 |

**验收红线**：**拆掉模块，能力必须立刻消失**（不是“禁用了”，是不存在）。

### P3 · 芯片与对话（v0.3，2~3 天）

| # | 任务 | 关键点 | 验收 |
|---|---|---|---|
| P3.1 | `EventRouter`（T0）：12 个触发点 | 冷却 + 去重 + 权重随机 | 低血量/敌对/弹尽各有播报，不复读 |
| P3.2 | `IntentMatcher`（T1）：归一化 → 别名 → 包含 → 正则 | 5 步匹配，<30ms | “扫描”“sm”“帮我看看周围”都能命中 |
| P3.3 | 槽位填充 `{n}{dir}{dist}{hp}{gun}{item}` | 中文数字转阿拉伯 | 播报数字正确 |
| P3.4 | 台词库装载 + 权重抽取 + 不重复 | `data/dronepal/lines/<pack>/*.json` | 两种人格语气可辨 |
| P3.5 | 聊天输入 UI | 快捷键开输入框（不占用原版聊天） | 打字→回复 <50ms |
| P3.6 | 语音：sound event 注册 + 队列 + 字幕 | 同一架同时只播一条 | 语音与字幕同步、多架不叠爆音 |
| P3.7 | 数字/方位音素拼读 | 0~99 用 20 条 ogg 拼 | “剩余 12 发”听起来自然 |
| P3.8 | 兜底话术 | 未命中意图 / 无芯片 | 不会哑火 |

**验收红线**：**断网、关掉所有外部服务，全部功能照常**（本来就不联网，但要写进测试项证明）。

### P4 · 饰品栏与 TaCZ 联动（v0.4，1~2 天）

| # | 任务 | 关键点 | 验收 |
|---|---|---|---|
| P4.1 | Curios 槽位 `drone` | `ICurio` + `CurioRenderer`（悬浮在身后） | 装进饰品栏即出现，取出即消失 |
| P4.2 | 无 Curios 时降级 | 召唤器物品走背包 | 不装 Curios 也能玩 |
| P4.3 | `mod_link`：弹药余量播报 | 读 TaCZ `IGun`/`IGunOperator` | 打空时播报“空了” |
| P4.4 | `mod_link`：命中/击杀播报 | 监听 TaCZ `api/event` | 打中有反馈 |
| P4.5 | `mod_link`：递弹匣 | 从机身库存投递 | 手上没弹时能补给 |

**风险**：TaCZ 1.2.0 的 API 与 1.20.1 分支可能有差异 → **P4 开始前先花半天读 1.21.1 分支的 `com/tacz/guns/api`**，不改代码只出结论。

### P5 · 打磨（v0.5，按需）

编队（2~3 架）、升级件（mk2/mk3 模块）、记忆档案（本地 json：上次死因/首次见到的生物）、充电座、HUD 美化、模型动画（GeckoLib 全套）。
