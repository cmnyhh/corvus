# 离线对话控制台

部署无人机并安装战术或话痨芯片后，直接输入 `/dronepal 你好` 或 `/dronepal say 你好`。普通玩家可使用。`/dronepal` 列出已装模块。试试“你是谁”“电量”“几点了”“讲个笑话”“扫描”“治疗”或“停火”。行动指令由服务端根据玩家自己的已部署无人机、实际模块和当前运行状态执行。

“你是谁”读取当前机体的产品名和呼号。战术芯片播报呼号及代称，话痨芯片优先使用昵称。可在铁砧上给终端命名。

| 输入 | 查询来源 |
|---|---|
| `/dronepal 配方 minecraft:torch` | 当前服务端配方的材料和产出数量 |
| `/dronepal 下一步干嘛` | 当前玩家满足上一级条件的可见进度 |
| `/dronepal 进度 minecraft:story/mine_stone` | 当前玩家完成指定进度的状态 |
| `/dronepal 枪械数据 tacz:m4a1` | 本机安装的 TaCZ 游戏枪包数值 |

## 数据包和资源包

数据包的 `data/huhu_dronepal/intents/` 定义精确别名、包含词和预编译正则。先匹配精确别名，再取最长包含词，再尝试正则。单字命令仅精确匹配。`response: line` 的 `line` 指向一个台词触发名。`data/huhu_dronepal/lines/<人格>/` 中的台词可以通过同一个 `trigger` 设置多个带不同 `id` 和正整数 `weight` 的候选。默认触发名为台词自身的 `id`。存在多个候选时，跳过上次播报的候选。`/reload` 同时替换服务端的意图、台词和人格配置。

例如带有 `"voice": "chatty/name"` 的台词会请求 `huhu_dronepal:voice/chatty/name`。要配音，请在客户端资源包中放置录音 `assets/huhu_dronepal/sounds/voice/chatty/name.ogg`，再在 `assets/huhu_dronepal/sounds.json` 加入以下事件。

```json
{
  "voice/chatty/name": {
    "sounds": ["huhu_dronepal:voice/chatty/name"]
  }
}
```

在游戏内启用资源包并重载客户端资源。未配置声音时仍显示文本。语音使用玩家声道，按芯片的 `voice_speed` 播放，每架无人机顺序播放，最多缓冲 8 段。

## 扫描字幕

发出 `/dronepal 扫描` 后，无人机会在本轮搜索完成时，通过机主的屏幕字幕报告最近的矿物和敌对生物。方位以玩家的位置和世界的东南西北为准，距离按格计算。手动扫描可以报告本轮没有目标，自动扫描只报告变化的发现。重复手动查询同一结果的间隔为 10 秒。静默芯片只提供扫描标记。

## 自动播报

服务端每秒检查低血（≤30%）、低电（<20%）、首次进入其他维度、入夜、开始下雨，以及已装模块由在线转为离线。数据链检测到弹药耗尽、玩家坠落至少四格、死亡和重生也会触发台词。事件播报共用芯片的概率和冷却。战术芯片的默认概率为 20%、冷却 8 秒，话痨芯片为 90%、冷却 2 秒。
