# Corvus 双足机甲裸机

Bedrock 几何 `geometry.service_frame`，格式 `1.12.0`。模型包含 26 根骨骼、834 个立方体和 5004 个已定义面。尺寸单位为 u，16 u = 1 格。

## 骨骼树

```text
root
└─ hip
   ├─ torso
   │  ├─ cockpit_glass
   │  ├─ core_ring
   │  │  └─ core_socket
   │  ├─ antenna
   │  ├─ mount_back
   │  ├─ shoulder_l
   │  │  ├─ arm_l
   │  │  │  └─ arm_l_fore
   │  │  │     └─ mount_arm_l
   │  │  └─ mount_shoulder_l
   │  ├─ thruster_l
   │  ├─ shoulder_r
   │  │  ├─ arm_r
   │  │  │  └─ arm_r_fore
   │  │  │     └─ mount_arm_r
   │  │  └─ mount_shoulder_r
   │  └─ thruster_r
   ├─ leg_l_upper
   │  └─ leg_l_lower
   │     └─ foot_l
   └─ leg_r_upper
      └─ leg_r_lower
         └─ foot_r
```

## 九种涂装的重着色区

九套涂装共用同一份几何。每套只改三个互不重叠的 UV 岛：紫光条 `(48,20,16,4)`、肩部主强调板 `(64,0,32,20)`、肩板边缘 `(96,0,32,20)`。肩部保留原有明暗纹理；所有重着色像素保持 alpha=255。四块指示/发光色和玻璃不随涂装替换。本次不含九张派生皮肤。

## 造型简化与验收边界

仅按本次参考图新建裸机，不包含肩载发射器、臂炮或盾。圆形插口以十段直边方块围合，内侧保留空腔和后壁，两扇滑门停在外侧；斜面装甲与风挡由旋转立方体形成，不含曲面网格。座舱内保留深色座位。参考图不可见的背轨、散热口和舱内布置是推定设计。
