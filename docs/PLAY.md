# Corvus 快速开始

完整的获取方式、模块数值、战斗与维护说明见**[游玩攻略](GUIDE.md)**。本文只列最短上手步骤。

使用 Minecraft 1.21.1、NeoForge 21.1.267 和 Java 21。把构建产物放入游戏实例的 `mods` 目录，启动游戏。必须同时安装 Curios API 9.x（NeoForge 1.21.1 版），它提供部署终端用的无人机饰品槽。TaCZ 提供游戏内枪械及弹药。多人游戏请在客户端与服务器安装同一版 Dronepal。

## 首次部署

生存模式先在工作台制作机架、伺服电机、电路板和装配台，再用装配台蓝图制作游隼。蓝图会列出所需材料。需要试验造型时，可在允许命令的世界里使用 `/give @s huhu_dronepal:drone`。

将终端放进 Curios 的无人机槽即可部署，取出终端可收起机体。按 F5 可以在第三人称查看跟随效果。

## 装卸和使用

- 靠近自己的机体，潜行并空手右击以打开面板。从背包拿起部件，放入对应的机身槽位。可按住 Shift 点击物品，在背包和机身之间快速移动。悬停在模块上可查看功能、功耗和型号特性。夜枭、游隼、拼装和磐石分别有 2、3、3、4 个模块槽。
- 电池为模块供电。在充电座放入煤炭和电池，即可查看充电状态。空手右击取出已充电的物品。
- 按住 V 打开遥控轮盘，移动鼠标选择功能后松开。功能随已安装的模块出现。照明、扫描和投递适合检验非战斗配置。
- 手持喷罐右击自己的机体，会立即换上相应涂装。铁砧可以给终端命名。
- 安装战术或话痨芯片后可输入 `/dronepal 你是谁` 或 `/dronepal 电量`。更多指令见[离线控制台](OFFLINE-CONSOLE.md)。

## 旧世界升级

旧机体 standard、scout 和 heavy 分别对应游隼、夜枭和磐石。旧模块按族和档位映射到原厂产品。旧通用电池迁移到同档铁砧电池，能量保留至新容量上限。建议升级前备份世界。
