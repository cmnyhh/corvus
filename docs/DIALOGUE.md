# Dronepal · 对话与语音规范（无 LLM）

## 1. 玩家输入怎么被理解

三步，全部本地、<30ms：

```
原始文本 → 归一化（去标点/全角转半角/小写/拼音首字母） → 意图匹配 → 槽位填充 → 台词 or 数据播报
```

**归一化**：`str.strip().toLowerCase().replaceAll("\\s+"," ")`，全角转半角，中文数字转阿拉伯（"十二"→12）。
**匹配顺序**（命中即停）：

1. **精确别名**：意图表里 `aliases` 完全相等（"扫描"）
2. **包含**：`aliases` 中任一出现在句子里（"帮我扫描一下"）
3. **正则**：`patterns`（`.*(多少|几).*(伤害|damage).*`）
4. **拼音首字母**：`sm` → `scan`（可选，防打错字）
5. 都没中 → 兜底话术

## 3. 台词库格式

`data/huhu_dronepal/lines/<pack>/<group>.json`：

```json
{
  "pack": "tactical",
  "group": "combat",
  "lines": [
    { "id": "hostile_near", "text": "{n} 个敌对目标，{dir}，{dist} 格。", "voice": "tactical/hostile_near", "weight": 3 },
    { "id": "fire_start",  "text": "开火。", "voice": "tactical/fire_start", "weight": 5 },
    { "id": "kill",        "text": "目标清除。", "voice": "tactical/kill", "weight": 2 }
  ]
}
```

- `{n}` `{dir}` `{dist}` `{hp}` `{gun}` `{item}` 由槽位填充；
- `weight` 控制同组台词出现概率（权重高 = 更常出现）；
- 同一 `id` 连续两次不重复（避免复读）；
- `voice` 为空表示只出字幕（战术芯片的“长句”一律只出字幕）。

## 4. 两种人格的差异（不是换个词，是换个节奏）

| 维度 | `chip_tactical` | `chip_chatty` |
|---|---|---|
| 句长上限 | 24 字 | 60 字 |
| 主动播报频率 | 0.2（只在关键事件） | 0.9（什么都想说） |
| 冷却 | 8 秒 | 2 秒 |
| 自称 | “本机” / 省略主语 | “我” / “人家” |
| 情绪词 | 无 | 大量（“诶嘿”“糟了糟了”） |
| 闲聊 | 拒绝（“闲聊不在任务范围内。”） | 主动展开 |
| 语音包 | 150 条，语速 1.15× | 260 条，语速 0.95× |

**示例（同一个事件 `low_health`）**

- 战术：`"生命体征 28%。后撤，或者先止血。"`
- 话痨：`"喂喂喂你血都快没了！快跑啊！那边那边！"`

**示例（`meta.insult`）**

- 战术：`"记录在案。"`
- 话痨：`"……我记住你了。"`

## 5. 语音实现

- 每条台词对应一个 sound event：`huhu_dronepal:voice/<pack>/<id>`；
- `VoicePlayer` 维护一个队列：同一架无人机同时只播一条，新的进队；跨无人机按 `SoundSource.PLAYERS` 声道，多架会自动叠但会降音量（`distanceDelay` 关闭）；
- 字幕：`ChatComponent` 形式显示在 HUD 底部 3 行，1.5 秒淡出；
- 数字播报用单独的音素拼读：`读数字(0~99)` 20 条 ogg + 位数拼接，避免 100 条数字音频。

## 6. 文案产出计划

| 内容 | 量 | 来源 |
|---|---|---|
| 战术台词 | ~150 条 | 我按触发点/意图手写，你删改 |
| 话痨台词 | ~260 条 | 同上 |
| 检索条目 | ~2000 条 | **脚本从 TaCZ gunpack json 自动抽取**（每把枪：伤害/口径/射速/弹匣）+ 原版配方 |
| 数字/方位音素 | ~40 条 ogg | 你录或我用 TTS 批量出（离线跑一次，不进游戏运行时） |
