# Corvus 游玩攻略

一架装在饰品栏里的随行无人机：会跟着你走、能挂 TaCZ 的枪、能扫描、能照明、能背货、会说话。
本攻略按「第一次上手 → 造出第一架 → 配装 → 战斗 → 日常维护」的顺序写，所有数值都取自当前模组数据。

**不联网、不接大模型、不改世界。** 它不会帮你放方块、挖矿或给你物品。

---

## 0. 装好它

| 组件 | 要求 |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.x（声明支持 21.1.0 及以上；实测基线 21.1.267） |
| Java | 21 |
| **Curios API** | **必需**，9.x（1.21.1 版）。没有它启动不了，也不会部署 |
| TaCZ | 可选，1.2.0。装了才能挂枪并真实开火 |
| FTB Teams | 可选。装了会按 FTB 队伍判定队友 |

单人游戏直接把模组丢进 `mods` 即可。多人服务器需要客户端与服务端装同一版。

## 1. 五分钟上手

1. **拿到终端**：生存里按下面的合成链做；创造模式在「随行无人机」标签页里直接取。
2. **放进饰品栏**：按 **G**（Curios 默认键）打开饰品界面，把终端拖进 **「无人机」** 槽。
   放进槽的瞬间，机体就会出现在你肩旁。
3. **让它跟着**：站定或走动即可。你原地转头时它会停在原处，方便你对着它操作。
4. **打开面板**：靠近机体，**空手按住 Shift 右键**它，打开配置面板，拖入电池、模块、枪和弹药。装了货舱模块后，面板里的**「货舱」按钮**可以打开货舱界面取放货物（见 §4.4）。
5. **召回**：把终端从饰品槽取出，机体立刻消失（内容物全部保留在终端里）。

> 只放背包、不放进饰品槽，是不会部署的。手持右键会把终端放回饰品槽的提示打给你。

## 2. 造出第一架「游隼」

游隼是标准本体的正规合成线，整条链跨三道工序。按顺序做（拼装机体另有一条更便宜的废料线，见 §3）：

### 2.1 先做装配台（工作台）

| 产物 | 材料 |
|---|---|
| 装配台 | 铁锭 ×4 + 铜块 ×2 + 活塞 ×1 + 铁砧 ×1 |

装配台是后面所有「子系统 / 核心 / 成品」唯一的生产地点，**工作台做不了这些**。

### 2.2 基础零件（工作台，可一次多做几个）

| 零件 | 配方 |
|---|---|
| 机架 | 铁锭 ×4 + 铜锭 ×2 |
| 伺服电机 | 铜锭 ×3 + 红石 ×2 + 铁锭 ×1 |
| 电路板 | 金锭 ×1 + 红石 ×4 + 石英 ×2 |
| 电池芯 | 铜锭 ×2 + 红石 ×2 + 纸 ×1 |
| 光学组件 | 玻璃 ×2 + 紫水晶碎片 ×1 |
| 散热片 | 铁锭 ×2 + 蓝冰 ×1（战斗、医疗模块要用） |
| 装甲板 | 铁锭 ×3 + 皮革 ×1 |

### 2.3 子系统（装配台）

| 产物 | 配方 |
|---|---|
| 飞控板 | 电路板 ×2 + 伺服电机 ×1 + 金锭 ×1 |
| 电调 | 电路板 ×1 + 伺服电机 ×2 + 铜块 ×1 |
| 动力总成 | 电池芯 ×2 + 电调 ×1 + 机架 ×1 |
| 传感模块 | 光学组件 ×2 + 电路板 ×1 |
| 武器接口 | 机架 ×1 + 伺服电机 ×2 + 铁锭 ×2 |
| 医疗泵组 | 电池芯 ×1 + 玻璃 ×2 + 糖 ×2 |

### 2.4 机体（装配台）

| 产物 | 配方 |
|---|---|
| **游隼机体** | 机架 ×2 + 动力总成 ×1 + 飞控板 ×1 + 传感模块 ×1 + 玻璃 ×1 |

### 2.5 电池（装配台，必须）

没电池 = 没有电 = 模块全部离线，只剩跟随和悬浮。

| 产物 | 配方 | 容量 |
|---|---|---|
| 万向 100 标准电池组 | 电池芯 ×3 + 机架 ×1 | 18 万 FE |
| 万向 200 标准电池组 | 万向 100 ×1 + 电池芯 ×2 + 铜块 ×2 | 35 万 FE |
| 万向 300 标准电池组 | 万向 200 ×1 + 电池芯 ×4 + 钻石 ×1 | 60 万 FE |

> 换个角度看：**游隼 + 装配台**首轮大约要 50 铁、46 铜，外加石英、紫水晶、金和活塞；电池另算。这是一件中期工程，不是开局十秒就能拿到的东西。

### 2.6 装配台怎么用

- 打开装配台：**9 个输入格** + 1 个产物格。
- 在**左侧的蓝图列表里点选**目标产物（列表会标出材料够不够，够了显示绿色圆点）。滚轮可以上下翻，也可以用 `‹` `›` 一个个翻。
- 把材料拖进输入格，点「开始装配」。
- 默认工时 **80 tick（约 4 秒）**，进度条走满后成品进入产物格。
- **关掉界面它会继续做**；中途拆掉装配台会把材料完整退还。
- 材料不足或产物格没空间时，装配会被拒绝并且不会扣材料。

## 3. 四款机体

| 机体 | 跨度 | 模块槽 | 弹药格 | 生命 | 单次伤害上限 | 可挂枪 | 获取 |
|---|---:|---:|---:|---:|---:|---|---|
| **游隼**（渡鸦系统） | 1.45 格 | 3 | 6 | 80 | 10 | 手枪/冲锋枪/步枪/狙击 | 装配台合成 |
| **夜枭**（渡鸦系统） | 1.10 格 | 2 | 4 | 56 | 8 | 手枪/冲锋枪 | 军用补给箱 |
| **磐石**（铁砧重工） | 1.80 格 | 4 | 8 | 144 | 12 | 全部（含 RPG） | 军用补给箱 |
| **拼装**（锈钉作坊） | 1.35 格 | 3 | 6 | 64 | 10 | 手枪/冲锋枪/步枪 | 装配台（废料）/ 遗迹补给箱 |

**拼装机体（废料线）**：装配台里用 机架 ×2 + 铁锭 ×6 + 铜锭 ×4 + 红石 ×3 + 玻璃 ×1 就能拼出来。它没有正规飞控和动力总成，所以便宜、也更容易出毛病（漏电、瞬移失败）。

**怎么选**：游隼是均衡原型机，什么都干得了；夜枭小而快、适合前期侦察，但只能挂小枪；磐石最耐打、槽位最多、能挂 RPG，代价是笨重、太阳能效率低；拼装便宜好开，但会漏电、可能故障。

### 4.3 货舱怎么打开

装了货舱模块后，配置面板（空手 Shift 右键机体）里会多一个**「货舱」按钮**：

- 按钮只在**货舱模块装好并且在线**时可用；没装或没电时按钮是灰的，鼠标悬停会写原因，不会打开空界面。
- 点开后是一个原版样式的容器界面，格子数就是模块的容量（万向 9 / 18 / 27，锈钉 12），右上角显示「已用 / 总格数」。
- **左键拿起、右键拿一半、Shift 点击整摞快速移到背包**；背包里的东西也能直接放回货舱，方便整理。
- 关掉界面时所有改动都已经写回终端，**不会复制也不会丢**。只有主人、在交互距离内、且这块终端就是当前装备的那一块才能打开；换人、走远、拔下终端都会被拒绝。
- 货舱界面开着时，无人机暂停自动拾取与自动投递（避免和界面抢同一份货物），关掉后立刻恢复。

### 4.4 怎么拿到

**民用三族（carry / light / solar）——装配台可造**，每族三档：

| 产物 | 配方 |
|---|---|
| 货舱核心 | 机架 ×1 + 箱子 ×1 + 伺服电机 ×2 |
| 照明核心 | 光学组件 ×1 + 荧石粉 ×2 + 铜锭 ×2 |
| 光伏核心 | 光学组件 ×2 + 铜锭 ×3 + 玻璃板 ×2 |
| 民用 Mk.I | 对应核心 ×1 + 机架 ×1 |
| 民用 Mk.II | 同族 Mk.I ×1 + 升级套件（电路板 ×2 + 铜块 ×1 + 紫水晶碎片 ×1） |
| 民用 Mk.III | 同族 Mk.II ×1 + 高级升级套件（电路板 ×3 + 钻石 ×1 + 下界合金碎片 ×1 + 散热片 ×2） |

> 升级必须**消耗同型号的上一档**，不能跳档，也不能把别的厂商同族件当垫脚石。

**锈钉 G1 六件——装配台用废料拼**（也可以继续从拆机箱翻）：击发器、测距仪、货筐、止血包、大灯、板子。成本比民用件低，但本身带故障、误报、闪烁等副作用。

**军用/医疗——只能从补给箱和商人处拿**：

| 来源 | 出现地点 | 概率 | 里面有什么 |
|---|---|---:|---|
| 军用补给箱 | 掠夺者前哨站 / 要塞走廊 / 末地城 | 42% | 铁砧战斗、渡鸦扫描、渡鸦链路、夜枭/磐石机体、铁砧与渡鸦电池 |
| 拆机补给箱 | 废弃矿井 / 沉船补给舱 / 海底废墟（大） | 35% | 拼装机体、锈钉电池 |
| 医疗补给箱 | 村庄神庙 / 雪屋 | 30% | 白鸦医疗 Gen1/2/3 |
| 牧师交易 | 村民牧师 | 12 / 24 / 36 绿宝石 | 白鸦医疗 Gen1/2/3 |

每个补给箱开一次只出一件。

**模块能做的事**：装上模块后，同一件模块会出现在 **V 轮盘**对应扇区，也会让 `/dronepal` 的对应指令生效。鼠标悬停在模块物品上能看到它的完整数值。

## 5. 电池与续航

| 电池 | 厂商 | 容量 | 充电上限 | 获取 |
|---|---|---:|---:|---|
| 万向 100 / 200 / 300 | 万向动力 | 18 万 / 35 万 / 60 万 FE | 300 / 400 / 500 | 装配台合成 |
| 渡鸦 R-1 / R-2 | 渡鸦系统 | 15 万 / 30 万 FE | 400 / 500 | 军用补给 |

**功耗常识**：模块只在**通电且已安装**时耗电。厂商会乘系数——万向 ×0.85、铁砧 ×1.1、锈钉 ×0.75、白鸦按原值。

典型组合（不含太阳能回充）：

| 玩法 | 模块 | 耗电 | 用万向 300（60 万） |
|---|---|---:|---:|
| 纯侦察 | 渡鸦 R-1 扫描 | 6 FE/t | 约 83 分钟 |
| 探索 | 渡鸦 R-2 扫描 + 万向 100 货舱 + 万向 200 光伏 | 约 13.3 FE/t | 约 37 分钟（晴天可净回） |
| 战斗 | 铁砧 Mk.II 火控 + 白鸦 Gen2 + 渡鸦 R-2 链路 | 约 30.8 FE/t | 约 32 分钟 |
| 辅助 | 万向 200 照明 + 白鸦 Gen2 + 万向 200 光伏 | 约 8.6 FE/t | 约 58 分钟 |

电量低于 **20%** 时，最耗电的那个模块会被自动关掉，HUD 变红；电量耗尽后模块全部离线，只剩跟随和悬浮（此时不耗电）。

## 6. 充电

| 项 | 数值 |
|---|---|
| 合成 | 铁锭 ×6 + 铜锭 ×2 + 红石 ×1 |
| 缓冲 | 32,000 FE |
| 线缆输入 | 2,000 FE/t |
| 烧煤兜底 | 1 块煤 = 4,000 FE，最多 200 FE/t（一座最多存 64 块） |
| 电池接收 | 按型号 300～1,000 FE/t（受下方倍率影响） |

**用法**：

- 手持电池（或装有电池的终端）右键充电座 → 放进去充电；空手右键 → 取回。
- **机体直接停在座上方**也能充，电会写回你终端里的那块电池。
- 座上方会显示当前电量、座内物品的电量条和它自己的模型，站着看就知道有没有在充。
- 拆掉座会把它和剩余的煤原样掉出来。

## 8. AI 芯片与说话

三款芯片决定它是谁：

| 芯片 | 风格 | 合成 |
|---|---|---|
| 战术芯片 | 冷静、短句、只报数据 | 电路板 ×1 + 红石 ×2 + 指南针 ×1 |
| 话痨芯片 | 话多、情绪化、主动播报 | 电路板 ×1 + 红石 ×2 + 书 ×1 |
| 静默芯片 | 只干活不吭声 | 电路板 ×1 + 红石 ×2 + 白色羊毛 ×1 |

对话全部在本地完成，不联网：

```text
/dronepal 你是谁        看机型和呼号
/dronepal 电量          看剩余电量
/dronepal 扫描          立刻扫描一次
/dronepal 治疗          用医疗模块回血
/dronepal 递弹          让机舱把匹配弹药递给你
/dronepal memory        看这架机的档案（首次启用、陪伴时长、重建次数）
/dronepal 帮我放个方块   她会说"我没有机械臂"——这是设计，不是 bug
```

> 台词显示在屏幕下方的固定字幕里，不挡视野；有配音的台词会同时播放提示音。

**一句闭嘴**：配置面板里和「货舱」同列的**「播报：开/关」**按钮是人格芯片台词的总开关，写在终端上（`dronepal_off_barks`），缺省为开。关掉后芯片不再主动播报（低血、低电、入夜、弹药播报等），但**手动 `/dronepal` 问答照常显示**，链路开关（`dronepal_off_link`）等其他模块开关各自独立，互不影响。

## 9. 挂枪与战斗

### 9.1 前置

1. 装 **combat 模块**（没它不能挂枪；拆最后一个战斗模块前必须先卸枪）。
2. 机体能承载这种枪：夜枭只能手枪/冲锋枪；游隼和拼装可到步枪（拼装还不能狙击）；磐石全都能挂，包括 RPG。
3. 枪要放得进**弹药格**：夜枭 4 格、游隼 6 格、拼装 6 格、磐石 8 格。每格一组，具体发数由弹种决定。

### 9.2 轮盘（按住 V）

| 扇区 | 作用 |
|---|---|
| 北 | 跟随 / 原地待机 |
| 东北 | 武器：**自动 / 保险** |
| 东 | 交战策略：被动 / 仅敌对 / 反击 / 协战 / 主动 |
| Shift + 东 | 开火模式（仅战斗 Mk.III：单发 / 点射 / 连发） |
| 东南 | 巡扫开关（需扫描模块） |
| 南 | 医疗开 / 关 |
| 西南 | 载物开 / 关（自动拾取）；**Shift = 立即投递** |
| 西 | 照明开 / 关 |
| 西北 | 链路播报开 / 关；**Shift = 递弹匣** |
| 中心 | 取消 |

点一下就会执行并刷新状态，**松开只关闭轮盘**，不会把最后一个选项再执行一次。

### 9.3 交战策略

默认是**反击**——只有你或无人机挨打了才会还手。这也是为什么你在创造模式里召出一只僵尸、站着不动时，它并不会主动开火。

想让它主动打怪，把策略切到 **仅敌对** 或 **主动**。五种策略都只会打**敌对生物**，都不会打村民、铁傀儡、悦灵、你的宠物和队友。

**友方判定只认 FTB Teams 的当前队籍**：主人本人永远受保护；同队成员也受保护；没装 FTB 时其他玩家都按普通玩家处理。原版 `/team` 不参与判定。

**子弹会穿过中立玩家**：你站在无人机和僵尸之间也不会挨打。只有服务器开了 PvP、你确认开了无人机 PvP（`/dronepvp enable` → `/dronepvp confirm`）、且对方确实是当前合法目标时，才会打中玩家。

### 9.4 姿态

- 锁到目标就**立刻转向**，可以一边跟着你跑一边朝侧后方的目标开火，不再需要先停下来。
- 云台能在机身两侧各 **75°** 内独立左右转、独立上下俯仰；超出范围时机身才补转。
- 开火前需要完成武器展开（云台从收纳角抬到水平），所以第一次交战会有零点几秒的举枪动作。
- 长枪收纳时会按长度限制下翻角度，RPG 这种长家伙不会戳穿机顶。

## 10. 扫描

装上 scan 模块后，**V 轮盘东南扇区就是巡扫开关**，默认开启。

| 档位 | 半径 | 能发现 | 标记持续 |
|---|---:|---|---:|
| 渡鸦 R-1 | 19 格 | 敌对生物 | 6 秒 |
| 渡鸦 R-2 | 29 格 | 敌对生物 + 煤/铁/铜 | 10 秒 |
| 渡鸦 R-3 | 38 格 | 敌对生物 + 全部矿石 | 20 秒 |
| 锈钉 G1 | 14 格 | 敌对生物（8% 扫描失败） | 4 秒 |

- 默认每 **15 秒**自动扫一次（服务端配置 `autoScanSeconds` 可改 5～300 秒）。
- 发现目标后：矿石是**青色方框**、怪物是**橙红色轮廓**，隔着石头也能看见；轮廓会跟着怪物移动。
- 同时无人机会用一句话报出最近的矿和最近的怪，例如「看这边！东面约 3 格处有铁矿石。小心，南面约 4 格处有尸壳！」
- 没有发现就不打扰你；关闭巡扫会立刻移除所有标记。
- **开了光影（Iris / Oculus）**时，扫描标记会自动改用粒子光点显示（自定义线框经常被光影管线跳过）。想强制固定某一种，改客户端配置 `config/huhu_dronepal-client.toml` 的 `scanMarkers`：`AUTO`（默认）/`LINES`/`PARTICLES`。

## 12. 游戏内手册

装了 **Patchouli（帕秋莉手册）** 时，游戏里会多一本 **「Corvus 操作手册」**：用 书 + 铜锭 + 红石 在工作台合成，打开后是 7 个分类、16 篇条目，含配方页与物品展示页，支持中英双语。

它是**可选**的：没装 Patchouli 时模组照常运行，只是没有手册，那本配方也不会加载（不会报错、不会留下"未知配方"）。

手册里的数值与本文一致；如果两者出现分歧，以游戏内手册为准（它随数据包实时读取）。

## 13. 常见问题

**Q：僵尸就在旁边，它为什么不打？**
默认策略是反击。切到「仅敌对」。另外和平难度下僵尸本身就会消失，先确认难度。

**Q：Right-click 机体没反应？**
要**空手** + **按住 Shift** + 靠近（几格内）。面板是唯一入口。

**Q：装了模块没效果？**
检查三件事：电池有没有电、模块是否在**当前机体**的槽位容量内、这类模块是否本来就只提供被动能力（例如 solar 只回电，没有按钮）。

**Q：它老是挡在面前？**
按住 Shift 它会停稳；战斗时子弹会穿过你和队友，不会打断射击。

**Q：旧存档能用吗？**
可以。旧机体 standard / scout / heavy 会自动映射成游隼 / 夜枭 / 磐石；只记录了「族 + 档」的旧模块会映射回原厂型号；旧三档通用电池会迁移到同档铁砧电池，电量保留。升级前建议备份。

**Q：为什么单发偶尔打偏？**
散布是设计的一部分：铁砧三档是 ±4.8° / ±3.2° / ±2°，锈钉 G1 是 ±9°。想要精准就升档。
