## 三句话概括产品

1. 玩家在**饰品栏装备一架无人机**（卸下即召回），它悬浮跟随、可以挂 **TaCZ 的真枪**开火。
2. 能力全在**模块**（7 族 × 3 档，3 个槽）+ **AI 芯片**（决定人格与说话方式）；**没装模块就没有对应能力**。
3. 对话**不接 LLM**：规则触发 + 本地检索 + 预录语音，离线、零延迟、不用 key。

## 关键决策（别重新讨论）

| 决策 | 理由（详见 SPEC §11） |
|---|---|
| 不接 LLM | 「搭档感」来自及时播报与检索，不需要生成；免 key、免审核、零延迟 |
| 不做 TTS | TTS 要绕开 MC 音量/字幕，且 2 秒延迟与短促播报冲突；用预录音素拼读 |
| 状态权威在**实体**，物品只存配置+快照 | 要战斗就必须是真实体；纯物品存状态只适合装饰 |
| 软失败（打坏 30 秒重建，内容物全保留） | 挫败感太重；且死亡掉落会造成复制漏洞 |
| 枪**不缩放**，用枪自带的 hand transform | 枪包已适配手部，缩放反而失真；只加固定偏移 + 极长枪一档 |
| 允许轻微穿模 | 为消除穿模做 AABB 测量/数据包不值 |
| 全软依赖（TaCZ / Curios / GeckoLib 可选） | 缺任何一个都能启动 |

## 第一步做什么

1. 通读 [SPEC.md](SPEC.md) §1–§8；
2. 装 NeoForge MDK，跑 P0（空 mod 能进游戏）；
3. **先做 P1.5 Spike**（S1–S7）：证明非玩家实体能拿 TaCZ 真枪开火 —— 这是整个项目的技术风险点，不通过就回退自定义投射物；
4. 再做 P1 跟随、P2 模块、P3 对话。

> P1.5 里要特别注意：`IGunOperator.fromLivingEntity()` 是 cast（Mixin 注入 LivingEntity），但**必须先 `draw()` 才能 `shoot()`**，弹药从实体的 `ItemHandler` 扣 —— 详见 SPEC §7。
