## 间距自检

`python3 tools/check_mill_layout.py` 直接解析上面两个类的常量，重建每个文字/条/槽矩形并检查交叠、
越界和行距（exit 0 = 干净）：

```
输出槽 (88,86) (108,86) (128,86)   等宽 20px 间距，全部落在右列 x 88–168 内
电条底 82 → 槽口顶 85（缝 3）      输出排 x 87–145 / 进度条 x 7–81（同带不相交）
标题 6 → 状态 21   Δ=15      状态 21 → 水标签 38  Δ=17
水标签 38 → 水条 50  Δ=12    水条 50 → 电标签 62   Δ=12
电标签 62 → 电条 74  Δ=12    电条 74 → 进度条 86   Δ=12
进度条 86 → 信息行 115 Δ=29  信息行 115 → 按钮 129 Δ=14
按钮 129 → 物品栏标签 159 Δ=30  物品栏标签 159 → 背包首行 172 Δ=13（标签下沿到格子 5px，不压格）
按钮上间距 6 / 下间距 8（到分隔线）  背包末排下沿 247 / 面板 250
PROBLEMS: none   ← 所有矩形两两无交叠，且全部在面板内
```

进度条与输出槽同在 y=86 带，但分别在 x 7–81 与 x 87–125，互不相交（左右两列，不是上下两行）。

```
$ python3 tools/check_mill_layout.py
... PROBLEMS: none   (exit 0)
```

* `gui.dronepal.ore_mill.percent` = `%s%%`
* `gui.dronepal.ore_mill.info` = `速度 ×%s · %s FE/件`（en：`Speed ×%s · %s FE/item`）

* `gui.dronepal.ore_mill.slot.output.byproduct` = `副产物槽：与输入矿种对应的粗料`

（原 `gui.dronepal.ore_mill.slot.output` 保留给旧引用，界面不再使用。）

## 复现截图

```
gradlew -I gradle/mill-visual.init.gradle runMillVisual
```

`MillVisual` 会开真实面板 → 保持水箱/电量满（绿灯、有进度、速度 ×1.5、耗电 1680）→ GUI scale 2 与 4
各拍一张 → 抽干水箱（黄灯、`停机：缺水`）→ scale 4 与 2 各拍一张。产物：
`artifacts/client/millgui-{working,3slots,working-scale4,dry,dry-scale4}.png`（2560×1600）。
`3slots` 是验收用的那张：开拍前先让机器真的跑单（稀有矿 → 额外槽碎粒，铁矿 → 主槽精矿 + 副槽
`coarse_iron`），所以三个槽里都是机器产出的真物品，不是手摆的。
日志里 `MILL_GUI_AUDIT` 一行记录每次拍摄时的 scale、面板位置、link、水/电百分比、速度与耗电。
