# 模型与尺寸约定（建模交接）

> 给做模型的人/AI：这些数字是**代码侧的硬约定**，模型必须按它建，否则技能、碰撞、挂载全部对不上。

---

## 1. 必须遵守的尺寸

| 项 | 值 | 为什么 |
|---|---|---|
| 整机跨度（含旋翼） | **1.45 × 1.45 格**（≈23.2 单位） | 和玩家肩宽接近，跟人不突兀 |
| 总高 | **0.87 格**（≈14 单位） | 含挂枪 |
| 机体本体 | **0.58 × 0.58 格** | — |
| **碰撞箱** | **0.7 × 0.7 × 0.7** | **只算机体，旋翼不参与碰撞**（否则卡门框、卡树叶） |

> 16 单位 = 1 格。全局缩放系数 0.66（相对早期 1.0 版本）。

## 1.5 型号（三种机体，各自一套模型）

| 型号 id | 显示名 | 跨度 | 模块槽 | 外观方向 |
|---|---|---|---|---|
| `peregrine` | **渡鸦系统 游隼** | **1.45 格** | 3 | 细长、钢蓝、线条干净（**本文尺寸以此为准**） |
| `owl` | 渡鸦系统 夜枭 | 1.10 格 | 2 | 更小更薄、暗色、侦察设备感 |
| `bedrock` | 铁砧重工 磐石 | 1.80 格 | 4 | 方正、暗红标识、外露装甲板与铆钉 |
| `scrap` | 锈钉作坊 拼装 | 1.35 格 | 3 | 拼装、外露管线、掉漆、焊痕 |

> 三种型号**共用同一套骨骼命名**（第 2 节），只是尺寸和细节不同 → GeckoLib 可以共用一套动画。
>
> 型号归属厂商：`scout → 渡鸦系统(CVS)`、`standard → 万向动力(OMD)`、`heavy → 铁砧重工(AHI)`。
> 建模时可以据此做外观区分：CVS 偏细长冷色、OMD 民用圆润+橙色标、AHI 方硬+暗红标。

## 2. 骨骼（名字不能改，代码按名字找）

```
root
├─ body                 机体（悬停 bob / 倾斜都作用在这）
│  ├─ pod_l / pod_r     左右侧舱（可选，概念图有推进器时用）
│  └─ sensor            顶部传感舱（可独立转动，做"扫描"动画）
├─ bottom               底盘
│  └─ gimbal            云台（**程序化驱动**：yaw 追目标 + pitch 俯仰）
│     └─ gun_mount      ★ 空骨骼，只有坐标，枪由 TaCZ 渲染挂在这里
└─ (可选) rotor_* 四旋翼（要做桨叶旋转动画时拆出来）
```

**要点**
- `gun_mount` **不要放任何几何**，它是一个纯定位骨；
- `gimbal` 的旋转范围：pitch **0°（交战）↔ +85°（枪口朝下收纳）**，yaw ±75°；
- 云台和枪的旋转**只由云台承担**，不要在 `gun_mount` 上再叠加"摆正"旋转（会和枪自带的 hand transform 打架，枪会歪）。

## 3. 挂载规范（和枪的关系）

| 项 | 约定 |
|---|---|
| 枪的位置 | `gun_mount` 下方 **0.22 格**为基准偏移；RPG/狙击等超长枪用 0.32 格 |
| 缩放 | **不缩放**（枪包已适配手部挂点，直接用它的 hand transform） |
| 旋转 | 不额外旋转，只有云台转 |
| 遮挡 | 在 `gun_mount` 上盖一块 **0.06 格厚的挂架板**，遮住枪与机体接缝 |
| 穿模 | **允许轻微穿模**，不做 AABB 测量、不做 per-gun 兼容表 |

## 5. 动画清单（GeckoLib / bedrock animation）

| 动画 | 用途 | 备注 |
|---|---|---|
| `idle` | 悬停浮动 | 上下 ±0.15 格，周期 2s，`body` 骨 |
| `boost` | 加速前倾 | `body` pitch −12°，配合移动速度 |
| `scan` | 扫描 | `sensor` 骨左右转 ±30°，周期 3s |
| `damaged` | 受损抖动 | 短促随机抖动，播 0.6s |
| `stow` / `deploy` | 武器收纳/展开 | `gimbal` pitch 0° ↔ +85°，0.45s / 0.35s |

> 云台**瞄准**不是动画，是代码每 tick 写的旋转；动画只负责"收纳/展开"这种固定动作。
